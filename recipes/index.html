    GitHub

    1. Open GitHub token settings.
    2. Under Repository access, pick Only select repositories, then dorrance5/dorrance5.
    3. Under Permissions, set Contents to Read and write.
    4. Generate the token, copy it, paste it above and tap Save and test.

    The token stays on this phone. Each save is a commit to recipes.json, and the site updates in about a minute.
